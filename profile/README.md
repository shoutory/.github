# Shoutory

**Say it once. Be heard everywhere.**

Shoutory is an open-source operating system for social content. Teams write, design,
plan, approve, schedule and publish to every major social network from one place,
with first-class Arabic (right-to-left) and English support.

- **Open source and self-hosted:** your content, accounts and data stay on your own infrastructure. A managed cloud edition is planned for teams that prefer not to run servers.
- **Built for teams:** shared calendars, review and approval before anything goes live, and a full audit trail.
- **AI with your approval:** an AI agent built on Claude and the Model Context Protocol drafts and adapts posts for each platform. Nothing is published without a person approving it.
- **Secure by design:** tenant isolation, encrypted platform credentials, and a durable job queue that never guesses about what was published.

Shoutory is in active development and has not launched yet. The source code will be
published here before launch.
